# Crypto Wallet

## Основные функции
- Просмотр списка криптовалют с базовой информацией
- Детальный экран с дополнительными метриками
- Система авторизации
- Сортировка монет по изменению цены

## Технологии
- **Архитектура**: MVVM
- **Фреймворк**: UIKit

## Реализация
- В ячейках используются плейсхолдеры для изображений (в api нет иконок монет)
- На детальном экране Suply посчитан и отображается в текущей монете, которую смотрит пользователь
- Добавлен Launch Screen
- Добавлен индикатор загрузки (спиннер) на кнопку Login

### Сортировка
- Три варианта в выпадающем меню:
  - По возрастанию
  - По убыванию
  - Сброс сортировки
- Сортировка происходит по изменению цены (процентам)
